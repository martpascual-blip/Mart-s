# Mart Emmanuel B. Pascual — Hunter Portfolio

A responsive, GitHub Pages-ready student portfolio with a blue-and-black dungeon/system-inspired theme.

## Files
- `index.html` — page content and editable lab task cards
- `style.css` — theme, layout, responsive design, animations, and hover effects
- `script.js` — mobile navigation, scroll reveals, active navigation, cursor glow, and optional music controls

## Preview locally
Open `index.html` in a browser. For best results, use a local development server (for example, VS Code Live Server).

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `sven-portfolio`).
2. Upload `index.html`, `style.css`, and `script.js` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then click **Save**.
6. Wait for GitHub to publish the site. Your page URL will appear in the Pages settings.

## Customize your portfolio
- **Lab cards:** In `index.html`, find `<!-- EDIT THESE CARDS -->`. Edit the title, description, status, date, and `href`. Duplicate an entire `<article class="lab-card panel reveal">...</article>` to add more.
- **Profile:** Update the introduction and player data in the Profile section.
- **Skills:** Change the skill names, descriptions, and inline bar widths (for example `style="width:55%"`).
- **Email:** Replace `your-email@example.com` in the Contact section.
- **Music:** Visitors can choose an audio file from their own device using the music control. The audio file is not uploaded to GitHub and is not included in the site.

## Notes
- The visual theme is an original blue/black fantasy-system interface and does not require copyrighted character images.
- Google Fonts are loaded online; system fallback fonts are used if unavailable.
- Replace all bracketed placeholders before submitting or sharing your portfolio.
